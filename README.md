# Glass Mind

Public source materials for **Glass Mind: The Operational Self-Model**, by Valentin Kalinin.

A provenance-grounded architecture for agents that can observe, attribute, explain, and revise their own causal behavior.

Status: working draft **0.1**. The paper describes an operational self-model; it does not establish phenomenal consciousness, autonomous general intelligence, or an independently audited benchmark result.

This repository publishes the papers already available on mind.glass. Internal implementation notes and experiment records mentioned in the papers are not included here.

Please use GitHub issues for corrections and questions about the published text.
